# Pokédex

A simple Pokédex application that lets users explore Pokémon and view detailed information about them.

## Features

* 🔍 Search for Pokémon by name
* 📋 Browse Pokémon information
* 🧬 View Pokémon types and abilities
* 📊 Display Pokémon stats
* 🖼️ View Pokémon sprites/images
* ⚡ Fetch Pokémon data from an external API
* 📱 Responsive and user-friendly interface

## Tech Stack

* **Frontend:** React
* **Language:** TypeScript / JavaScript
* **Styling:** CSS
* **API:** PokéAPI

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd pokedex
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by your development server.

## API

This project uses **PokéAPI** to retrieve Pokémon data.

API documentation:

[https://pokeapi.co/](https://pokeapi.co/)

1. Launch the application.
2. Search for a Pokémon.

4. Explore its stats, types, abilities, and other information.
